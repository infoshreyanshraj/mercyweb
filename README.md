# MERCY AI Website

A responsive, single-page MERCY AI landing site using the supplied logo and a violet Liquid Glass-inspired design.

## Included
- `index.html` — complete website
- `assets/mercy-logo.png` — supplied MERCY logo

## Preview locally
Open `index.html` in a modern browser.

## Publish
Upload the contents of this folder to GitHub Pages, Netlify, Vercel, or your preferred static host.

## Add release downloads later
In `index.html`, find the `#downloads` section. When you have the final files hosted, replace the "Coming soon" status elements with links to the APK and EXE, for example:
`<a class="button primary" href="downloads/mercy.apk" download>Download APK</a>`

The site currently does not claim the APK or EXE is available. Feature descriptions are framed as planned/intended where appropriate.
